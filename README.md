## 📌 Project Overview

This system bridges the gap between customer interaction (CRM) and core inventory/sales execution (ERP). Built with safety and scalability in mind, it provides an intuitive administrative dashboard alongside a strongly typed backend ensuring complete data consistency across complex multi-step transactions.

---

## ✨ Key Features

* **Transactional Integrity:** Guarantees zero data loss or partial updates during critical actions like sales order confirmations and sales challan creation via Prisma transactions.
* **CRM & Sales Pipelines:** Track customer accounts, leads, order statuses, and operational workflows end-to-end.
* **RESTful API Architecture:** Clean, modular backend design written in TypeScript using Express, featuring comprehensive input validation and standardized error handling.
* **Responsive Dashboard:** Modern React-based UI for real-time operation tracking and data management.
* **API Documentation:** Fully documented API endpoints using Postman collection schemas.

---

## 🛠️ Tech Stack

* **Frontend:** React, HTML5, CSS3, JavaScript (ES6+)
* **Backend:** Node.js, Express.js, TypeScript
* **Database & ORM:** PostgreSQL / SQLite, Prisma ORM
* **Tooling & Docs:** Postman, Git, npm
